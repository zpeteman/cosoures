# Semester 3 Course Materials

## Overview

This directory contains comprehensive course materials for semester 3, including solved exams and problem sets for various subjects.

## Course Structure

Each course directory follows this structure:

```
[course_name]/
|── [course_chapters]
|── [problem_sets]
└── README.md     # Course-specific documentation
```

The structure of the ``solved problem set` follows this structure:

```
solved_problem_sets/
|── [course_name]/
|   |── [problem_set_XX]
|   |   |── problem_set.pdf # The solved Problem set.
|   |   |── problem_set.tex # The LaTex solved source.
└── README.md     # documentation
```

The structure of the ``solved Exams` follows this structure:

```
solved_exams/
|── [course_name]/
|   |── [year]
|   |   |- Normal/
|   |   |  |── exam.pdf # The solved exam.
|   |   |  |── exam.tex # The LaTex solved source.
|   |   |- MakeUp/
|   |   |  |── exam.pdf # The solved exam.
|   |   |  |── exam.tex # The LaTex solved source.
└── README.md     # documentation
```

## Available Courses

- `algebra_IV/`: Advanced Linear Algebra.
- `cs/`: C the programming language.
- `analysis_IV/`: Advanced series and sequences.
- `digital_culture/`: Digital media and culture studies
- `rigid_body_mechanics/`: Advanced Mechanics.
- `analysis_V/`: multivariable calculus.
- `probability_and_statistics/`: introduction to probability.
